# Development journal

These files are the chronological, unedited development log of fakelinux —
session notes, debugging diaries, and handoff summaries written while the
project was being built. They are kept for posterity: most of the hard-won
Apple-Silicon and Linux-ABI trivia in this project was discovered the hard way
and is recorded here.

They are **not** maintained reference documentation. For that, see the curated
docs one level up (`docs/theory.md`, `docs/compatibility-roadmap.md`,
`docs/known-issues.md`) and the top-level [`README.md`](../../README.md).

Roughly chronological:

- `diary.md` — the main running diary.
- `history.md` — condensed history of milestones.
- `handoff.md` — most recent state-of-the-world handoff notes.
- `context.md` — a captured session-context snapshot.
- `session-2026-04-13.md`, `session-2026-04-14*.md` — individual session logs.
- `continuing-prompt.md` — a working prompt used to resume development.
